# 阶段收口记录未提交面，报告基线用本波 diff

> 来源：L-2026-09-27-007｜证据：S7 复盘 §3-8、§3-9、§2-15（跨阶段遗留未提交改动致修复波报告 status 面大于任务预期；Task5 时点已 5M + 4??，收口后仍留 1 个未跟踪文件）｜落地：2026-09-28

1. **每个阶段收口前**，用只读 `git status --porcelain -uall` 盘一次工作树，把「本阶段未提交面」逐项记录进该阶段报告——未提交也须留痕，禁止让改动跨阶段静默累积。提交动作受全局 Git 写操作禁令约束，**仅用户显式授权后**才可执行。
2. **修复波 / 阶段报告的 git 基线**一律用**本波 diff**（`<BASE>..<HEAD>` 或 fix-base 快照对比），**不得**用整树 `git status`。

**反例**：修复波报告贴整树 `git status`（混入上一阶段遗留的 5M + 4??），读者无法分辨哪些面是本波改动、哪些是历史累积。
